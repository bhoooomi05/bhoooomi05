## 🚀 Featured Projects

### TraceNet — AI-Powered Misinformation Detection

A multimodal misinformation detection and tracking platform that analyzes text and images to identify potentially manipulated or misleading content, presenting AI predictions, confidence scores, and flagged content through a React interface built for non-technical users. **🏆 Colloquium Hackathon Winner, 2026.**

| Layer      | Technology                                |
| ---------- | ------------------------------------------ |
| Frontend   | React                                      |
| AI/ML      | Random Forest, Gradient Boosting, XGBoost  |
| Approach   | Multi-modal (text + image) classification  |

### Ledgerly (Corderz) — AI-Powered Personal Finance Management

A full-stack personal finance platform that uses OCR and AI-assisted processing to extract receipt data, categorize expenses, and present financial information through a web dashboard. Built collaboratively.

| Layer            | Technology                                  |
| ----------------- | -------------------------------------------- |
| Frontend          | HTML, CSS, JavaScript                        |
| Backend           | Python, Flask                                |
| AI / Computer Vision | Tesseract OCR, OpenCV, Google Gemini API |
| Database          | SQLite, PostgreSQL (production)              |

Features: receipt OCR, expense categorization, financial dashboard, AI-assisted insights, voice expense entry, authentication, schedule management.

[![Corderz](https://github-readme-stats.vercel.app/api/pin/?username=bhoooomi05&repo=Corderz&theme=nord&hide_border=true&bg_color=0F172A&title_color=7DD3FC&text_color=C9D1D9&icon_color=7DD3FC)](https://github.com/bhoooomi05/Corderz)
